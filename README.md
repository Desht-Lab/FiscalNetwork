# Fiscal Network — сеть стран по структуре доходов госсектора

Интерактивная платформа Desht: 95 стран (IMF GFS, сектор S13, последний доступный год ≥ 2021), три варианта сети
(Брей-Кёртис по % ВВП и по % доходов, косинус), карта мира по сообществам, режимы Казахстана (KAZ_ipn, KAZ_2026, узлы по годам).

- `index.html` — платформа, самодостаточная (данные внутри). Внешние зависимости: d3 7.9, d3plus 2, topojson-client 3.1, карта world-atlas 2.0.2 с CDN.
- `platform_data.json` — те же данные отдельным файлом (узлы, рёбра, кластеры, мета).
- `build/` — скрипты сборки и шаблон тела страницы, см. `build/README.md`. Исходные Excel-файлы лежат в рабочей папке проекта и в репозиторий не включены.

Открыть: https://desht-lab.github.io/FiscalNetwork/
